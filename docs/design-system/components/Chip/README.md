A small rounded label in `caption`: tinted with a panel's `-soft` color and that panel's text color, or `chip-neutral` (`sunken`), `chip-brand` (`brand-soft`), `chip-late` (`danger-soft`).

**You provide:** one or two words. A late chip says so in words ("2 days late").

- Chips are 28px tall labels, not buttons. If one is a link, give it a 48px hit area with padding or a pseudo-element.
- A chip takes the color of the panel it belongs to: Chore chips are amber, even inside To-do.
- Don't stack more than three in a row.
